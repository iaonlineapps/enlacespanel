    Esta página

    Tu página se ve en:

    Dominio propio (opcional)

    Si tienes un dominio para esta página (por ejemplo laura.com o enlaces.laura.com), escríbelo aquí y tu página se abrirá directamente en él, sin nada detrás.

    Cómo conectar tu dominio
    1. En la web donde compraste el dominio, crea un registro A que apunte a la IP pública de tu casa (o un CNAME a tu DNS dinámico).
    2. En tu proxy con HTTPS (Nginx Proxy Manager, Caddy, Cloudflare Tunnel…) añade ese dominio y envíalo a esta Raspberry, al puerto .
    3. Escribe el dominio aquí y pulsa Guardar. El enlace, el botón Compartir y el código QR usarán tu dominio.

    Servidor (administrador)

    La dirección con la que se entra desde Internet, por ejemplo https://enlaces.midominio.com. Se usa para los enlaces que compartes y para los QR de todas las páginas que no tengan dominio propio. Déjala vacía para usar la dirección del navegador.
